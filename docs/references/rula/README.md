# RULAの実装調査と原典確認の範囲

確認日: 2026-10-13 JST。対象コミット: `1214b9bf67b1b18fe3e33e7a3b4eeab3981ef880`。調査対象: `RULAworkseet.html` と `rula.html`。アプリの機能・入力文・配列・計算式は変更していない。

## この記録から確定できること

以下は**リポジトリの実装についての説明**である。外部の原典を取得できなかったため、原著に基づく正式RULAの観察手順・分類規則・全表一致を確認した説明ではない。原典のURLを掲載したことと、その本文を取得して読んだことを区別する。

`rula.html:20–21` はRULAを Rapid Upper Limb Assessment と展開し、上肢を中心に首・肩・腕・手首等の作業姿勢の負担を短時間で評価する観察手法として説明している。一方、同ファイルの25–26行は本デモを「RULAの考え方を参考にした簡易版」「厳密なRULA計算ではなく、姿勢の傾向を直感的に理解することを目的」と説明する。これが確認できるアプリ自身の位置づけである。

正式RULAの点数体系を説明するには、姿勢だけでなく筋活動、外力・荷重、複数部位の組合せを段階的に扱う点を説明する必要がある。現アプリの手入力ワークシートでは、下記の要素が実装されている。主画面の体幹・膝を使った独自の0～100点計算は、この組合せ表計算を行っていない。

| 段階 | 本実装で入力・処理するもの | ソース |
| --- | --- | --- |
| A側の部位分類 | 上腕の屈曲・伸展、肩の挙上・外転・支持、前腕、手首の屈曲/伸展に対応する選択肢と偏位、手首のひねり | `RULAworkseet.html:49–92` |
| Table A | 調整済み上腕1～6、前腕1～3、手首1～4、ひねり1～2の組合せを配列で照合し、姿勢スコアAを得る | `:219–226,317–330` |
| A側の加算 | 筋使用0/1点と荷重/負荷0～3点を、姿勢スコアAへ加算する | `:100–116,332–335` |
| B側の部位分類 | 首・体幹の姿勢、ひねり・横曲げ、脚と足の支持 | `:148–180` |
| Table B | 調整済み首1～6、体幹1～6、脚1～2の組合せを配列で照合し、姿勢スコアBを得る | `:227–234,337–347` |
| B側の加算 | 筋使用0/1点と荷重/負荷0～3点を、姿勢スコアBへ加算する | `:191–207,349–352` |

Table Cは第三の身体部位群ではなく、A側とB側を組み合わせる最終照合表である。A/Bは単純に全部位点を足したものではない。例えば、上腕3・前腕2・手首2・ひねり1の場合、Table Aの値は4。この値へ筋使用1、荷重1を足すとA側合計6。首2・体幹3・脚1のTable B値も4で、筋使用1、荷重1を足すとB側合計6。Table Cの行6・列6は7。この例は保存した実装配列から計算したもので、原典との一致を保証する例ではない。

画面の判定文 (`:133–136`) は1/2「許容できる姿勢」、3/4「さらなる調査が必要。改善が必要な場合がある」、5/6「さらなる調査が必要。すぐに改善が必要」、7「調査を行い、直ちに改善を実装すること」。これは本画面の文言である。原典における各行動水準の条件、長時間維持等の留保、訳の正確さは未確認。

## 観察と選択についての確定・未確認

ワークシートは観察者がselect/checkboxを操作するフォームである。角度や重量を数値で入力する欄はなく、選択した整数の分類値を `getV()` が取得する (`:310–314`)。カメラ測定・MediaPipe・主画面の状態は読み込まない。したがって「前腕60～100度を自動検出する」「カメラ値から手首のひねりを決める」といった説明は実装に反する。

フォーム上の筋使用選択肢は、A/Bとも「動的 / 頻度が低い (+0)」と「静的(1分以上保持) または 反復(4回/分以上) (+1)」。荷重/負荷選択肢は、A/Bとも「2kg未満 (断続的) (+0)」「2kg - 10kg (断続的) (+1)」「2kg - 10kg (静的/反復) (+2)」「10kg以上、または繰り返しの衝撃 (+3)」。本実装は回数、保持時間、実際の力を計測しておらず、AとBの選択もそれぞれ独立している。荷重のkg表示は画面の入力分類であり、アプリが測定した腰部力ではない。

原典による観察対象姿勢の選び方、作業周期・観察時間、左右のどちらを評価するか、最も負担が高い姿勢を必ず選ぶか、角度の基準線・屈伸の符号、筋活動と荷重をどの群にどう適用するかは、今回取得できた外部原典では確認していない。本実装にもそれらを定める観察手順がない。文書に独自の必須手順として足さない。

## 原典・機関資料の取得状況

本アプリがリンクしている [Cornell University: RULA](https://ergo.human.cornell.edu/ahRULA.html) を実際にHTTPSで要求したが、実行環境のproxyが `Tunnel connection failed: 403 Forbidden` を返し、本文を取得できなかった。Cornellワークシート候補 `https://ergo.human.cornell.edu/Pub/AHquest/CURULA.pdf` も同じ結果。PDFの実在・内容・改訂版も今回確認できていない。

RULA原著として照合対象にする書誌候補は McAtamney L, Corlett EN, “RULA: a survey method for the investigation of work-related upper limb disorders,” *Applied Ergonomics*, 1993, 24(2), 91–99, DOI [10.1016/0003-6870(93)90080-S](https://doi.org/10.1016/0003-6870(93)90080-S)。DOI resolver、ScienceDirect、PubMedの候補URL、Crossref書誌APIを実際に要求したがproxyで拒否された。**書誌候補と原著取得済みの証拠を混同しない。本調査では原著本文・表・公式書誌の原文を保存できていない。**

ほかに作者関連のErgonomics.co.uk、政府機関HSE/CDC/OSHA、Europe PMCも取得を試みたが、同じ環境内で取得できなかった。GitHubの公開ページは取得可能だったが、未認証のコード検索ではログインが必要で、正式表の原文を得られなかった。これをRULA出典として採用していない。具体的なURLと取得条件は [retrieval-attempts.json](retrieval-attempts.json) に保存する。
